# Public Material Rights Review v1.13.0

## Reviewed Public Material

The proposed v1.13.0 addition contains generic lifecycle and feasibility
guidance, source-free tests, and release-control documents authored for this
package.

## Exclusions

The public candidate must not contain a private path, Study name, protocol,
data, ethics/access/registration evidence, result, manuscript, source
material, user decision, runtime receipt, credential, or copied external
scholarly content.

## Review Result

The material is suitable for Apache-2.0 publication only as generic source
code and documentation, subject to the accountable human's separate release
decision. This review does not establish rights for a real Study, hosted
Release, or installation target.
