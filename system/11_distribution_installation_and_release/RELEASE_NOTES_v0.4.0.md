# Release Notes: v0.4.0 Draft

Status: historical pre-C3 draft snapshot. These notes are not published Release notes and do
not authorize a tag, GitHub Release, installation, or public capability claim.
They must be reconciled with the exact admitted ledger records before C4.

## Intended Scope

v0.4.0 is intended to be a bounded governance-and-records expansion. Its
candidate material adds machine-checkable capability truth, current-versus-
historical release separation, a metadata-only bounded-autonomy authorization
record, a metadata-only data/provenance register, a release-control record
contract, and synthetic cross-record assurance.

The final published scope must name only capabilities explicitly admitted for
the exact release. R40-03 remains excluded: v0.4.0 does not provide specialist
role cards, agent runtime, delegated authority, hidden background work, or
multi-agent orchestration.

## Intended Boundaries

The candidate does not add real-data access or processing, clinical decision
making, ethics/DUA/privacy/compliance certification, scientific analysis or
final conclusions, automatic external login/download, journal submission,
automatic release, or technically immutable GitHub Releases. Metadata records
and synthetic tests do not establish approval, legal rights, data access,
runtime parity, or release readiness.

## Validation To Be Recorded Before Publication

- exact clean candidate commit and candidate-to-baseline review;
- full local suite with supported profiles and exact Workspace Framework
  `v0.1.1` validation;
- Windows, Ubuntu, and macOS CI for the exact intended release commit;
- final material/rights, dependency, workflow, public-surface, and release-
  integrity review; and
- accountable-human capability admission and C4 release authorization.

## Installation And Rollback

After publication, users must install only the exact `v0.4.0` tag and matching
GitHub Release. They must not install `main`, an untagged candidate branch, or
this draft. Update and rollback behavior remains governed by
`INSTALL_UPDATE_ROLLBACK.md`; neither action may alter project data, workspace
state, or private bindings.
