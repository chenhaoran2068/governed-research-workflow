# V1.2.0 Release Notes Source

Status: version-neutral source text for a later matching GitHub Release. It
describes the v1.2.0 versioned source scope only and does not prove an annotated
tag, GitHub Release, public availability, installation target, or runtime
update.

## Addition

- `GRW-CAP-120-01`, a generic metadata-only Controlled Experience Vocabulary
  And Reference-Index Contract with four blank JSON templates and matching
  schemas: controlled experience vocabulary, experience source inventory,
  experience mapping decision, and experience reference index.
- Explicit caller-named, read-only structural validators and synthetic positive
  and negative fixtures for the vocabulary and reference-index formats.
- Guidance that separates terminology, source identity, represented human
  mapping decision, reference-index retrieval link, project memory, promotion,
  and formal rule authority.
- A public skill route that requires named metadata inputs and stops before
  source-body/pointer reading, discovery, real mapping, promotion, rule change,
  administration, or unknown boundaries.

## Explicitly Not Added

No real vocabulary, source inventory, source reading, source hashing, source
classification, tagging, mapping, promotion, rule/template/checklist/skill
integration, data action, external contributor intake, upload/download helper,
retrieval, RAG, generic writer, agent runtime, delegated authority, Framework
change, Release action, or runtime installation.

## Compatibility

The frozen v1 public interface contract remains unchanged. Public profiles
remain `standalone` and `framework_integrated`; the existing exact Framework
binding remains validation-only. Existing Study workspaces, project memories,
promotion queues, formal rules, local vocabulary records, inventories, and
reference indexes are not migrated or read by this release scope. A structural
record or validator result never establishes source truth, human authority,
access, compliance, promotion eligibility, public-release identity, or
installation identity.
