# GRW-CAP-200-01 Public Capability Admission

## Source Scope

`GRW-CAP-200-01` is admitted only for the proposed `v1.10.0` public source
scope. It provides explicit, metadata-only routing from a human-confirmed
future-Study lifecycle route to a user-named compatible ethics-preparation
module.

## Required Caller Inputs

- one compatible module and caller-supplied public module manifest;
- one exact Study root;
- one material mode: `actual_submission` or `test_public`; and
- the exact protocol and compliance inputs permitted for the preparation task.

## Refusal Boundary

The route must refuse module or Study discovery, automatic Skill invocation,
project scanning, real-material reading, governance inference, application
creation, submission/upload, lifecycle-gate advance, data access, external
service action, and any installed-module or runtime claim.

A manifest, template, generated draft, field check, or structural validation
does not prove ethics approval, medical-research registration, data access,
institutional compliance, human authorization, or readiness to process real
material.

This source admission is not an exact candidate commit, remote-CI result,
protected-main merge, C4 authorization, hosted Release, or local-adoption
claim. Those require separately recorded evidence.
