# Release Notes: v0.6.0 Candidate Draft

Status: local draft for a future exact candidate commit. It is not published
Release notes and must be re-reviewed after the exact candidate identity,
capability admission, CI, and C4 decision are known.

## Proposed Addition

- metadata-only Workflow And Evidence Control Bundle contract with six typed
  records;
- optional canonical JSON SHA-256 baseline comparison;
- blank templates, synthetic fixtures, and an explicitly invoked read-only
  structural validator; and
- visible revision/downstream-impact representation and refusal checks.

## Explicit Non-Additions

v0.6.0 does not process data, retrieve source content, establish citation
entailment, verify human identity or authorization, make a scientific,
compliance, Gate, journal, submission, or release decision, prevent a
same-authority rewrite, provide an agent runtime, or synchronize/install a
local runtime.
