# v1.18.0 Public Material And Rights Review

Status: candidate review

## Included Material

- newly authored generic Study-status contract material from the accepted but
  unpublished v1.17 candidate;
- newly authored generic paper repository standard and blank templates;
- JSON schemas, deterministic local helpers, and synthetic test fixtures;
- links to official GitHub documentation and openly accessible published
  reproducibility studies used as external reference pointers.

## Excluded Material

- real Study status, data, code, results, manuscripts, author records, ethics
  or data-use documents, repository credentials, private paths, and release
  receipts;
- any named project candidate files or other project-specific package;
- copied third-party text, proprietary manuals, journal instructions, patient
  data, private keys, tokens, and credentials.

The external links are citations, not copied source payloads. The repository
license applies to this package's authored material; it does not relicense
linked material or any future Study content.

Automated scanning supports but cannot replace accountable-human privacy,
rights, authorship, and release review.
