# Governed Research Workflow v1.21.0

## Added

- Read-only reconciliation preview for a caller-named Study-status snapshot.
  It classifies snapshot compatibility and reports missing or mapping-required
  metadata without writing a Study or inferring a lifecycle decision.
- Generic manuscript-writing and linked-review guidance for narrative weight,
  Results roles, information placement, limitations, eligibility and flow
  displays, claim/display linkage, and candidate-package reconciliation.
- A blank linked-review checklist and an expanded claim/display review
  template.

## Changed

- The existing `GRW-CAP-150-01` manuscript route can load the new guidance
  when a selected released version contains it and a named existing-Study task
  needs that bounded support. This is not a new capability identifier or an
  automatic route.

## Not Included

This release does not discover or read Studies automatically; access data;
write manuscripts; choose a journal, profile, or reporting guideline; make
scientific, governance, or submission decisions; create repositories; or
perform a network action beyond normal package release distribution.
