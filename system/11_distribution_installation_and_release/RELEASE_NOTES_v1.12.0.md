# Governed Research Workflow v1.12.0

## Added

- `GRW-CAP-220-01`, a narrow optional consumer boundary for an explicitly
  configured, reading-Skill-owned managed reading knowledge service.
- A blank metadata-only handoff schema and template for a separately
  human-approved transfer to one named existing Study.
- Exact Framework v0.4.0 synthetic integration validation.

## Boundaries

- The System does not require, discover, install, configure, inspect, or
  operate a Framework service, reading Skill, reference manager, or Zotero.
- It cannot read, download, copy, parse, quote, summarize, retain, synchronize,
  or transfer a paper, PDF, source excerpt, dossier, knowledge card, or manager
  database.
- A handoff can contain only declared metadata and does not establish source
  support, relevance, governance, design, result authority, or any approval.

## Compatibility

The frozen v1.0.0 public interface remains unchanged. The framework-integrated
profile declares the exact Workspace Framework v0.4.0 contract. A public
release and local installation require their own exact tag, matching Release,
and local-adoption evidence.
