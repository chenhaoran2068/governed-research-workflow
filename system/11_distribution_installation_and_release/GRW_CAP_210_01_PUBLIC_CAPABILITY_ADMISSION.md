Release, installation, or runtime record.

## Scope

`GRW-CAP-210-01` adds generic System routing text that distinguishes a
user-requested reading of a specified scholarly paper from a possible new
Study. It can name a separately maintained reading Skill as optional, but the
user must select that route separately.

## Boundaries

The capability does not discover, invoke, install, configure, or verify a
Skill. It does not read, download, copy, parse, quote, summarize, index,
classify, or retain a paper; inspect a manager, workspace, or knowledge
service; create any reading, knowledge, experience, mapping, rule, promotion,
Study, governance, or release record; or establish an authority or runtime.
