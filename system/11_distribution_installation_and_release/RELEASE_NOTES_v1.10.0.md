# Governed Research Workflow v1.10.0

## Added

- `GRW-CAP-200-01`, an explicit, metadata-only bridge from a
  human-confirmed future-Study lifecycle route to a user-named compatible
  China-Mainland ethics-preparation module.
- Public route guidance and synthetic tests for required caller inputs,
  authority boundaries, and out-of-scope stops.

## Boundaries

- No automatic module or Study discovery and no automatic Skill invocation.
- No project scanning, real-material reading, ethics/access/registration
  inference, application generation, submission/upload, gate advance, data
  access, external service action, or runtime claim.
- The initial compatible ethics module is limited to researcher-initiated
  observational research in China Mainland. Causal/treatment-effect and trial
  routes remain separate specialist or future-Charter work.

## Compatibility

The frozen v1.0.0 public interface and the exact Workspace Framework v0.2.0
contract remain unchanged. A public release and local installation require
their own exact tag, matching Release, and local-adoption evidence.
