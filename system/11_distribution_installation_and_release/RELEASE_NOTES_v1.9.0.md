# v1.9.0

`GRW-CAP-190-01` adds lightweight, human-governed navigation for a possible new
Study expressed in ordinary language. It produces one visible route
recommendation with facts, unknowns, and risks, then requires human
confirmation before detailed lifecycle routing.

It adds no project creation, real-material access, data operation, research
executor, governance determination, schema, validator, dependency, Framework
change, agent runtime, network action, or automatic installation.
