# v1.18.1 Release Gate

Release remains blocked until the selected candidate commit passes declared
local and remote validation, receives affected-scope and protected-main review,
and becomes the target of a separately verified annotated tag and matching
GitHub Release.

The accountable human authorized the naming-contract revision, System release,
local adoption, and portal synchronization. That authorization does not permit
a failed candidate, mismatched tag, failed CI result, or unreviewed public
surface to be released.
