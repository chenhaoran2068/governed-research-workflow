# GRW-CAP-220-01 Public Capability Admission

Status: v1.12.0 source-scope admission only. This document is not a hosted
Release, installation, or runtime record.

## Scope

`GRW-CAP-220-01` adds generic System routing, a blank metadata-handoff schema,
and a blank template for a user-selected `scholarly-reading-knowledge` service.
The service is optional, owned by a separately maintained reading Skill, and
may hand only separately human-approved metadata to one named existing Study.

## Boundaries

The capability does not discover, invoke, install, configure, or verify a
Framework, Skill, service, reference manager, Study, paper, PDF, dossier, or
knowledge card. It does not read, download, copy, parse, quote, summarize,
index, synchronize, transfer, or retain source content; create a real handoff;
or establish access, source support, governance, design, result, or runtime
authority.

## Admission Decision

The accountable human accepted the generic source-free consumer scope and
authorized its controlled implementation in the active Codex conversation on
2026-08-09. Candidate, CI, PR, protected-main, annotated tag, matching GitHub
Release, and local adoption remain separate evidence classes.
