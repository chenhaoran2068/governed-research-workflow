# v1.14.0 Release Gate

Release remains blocked until the selected candidate commit passes declared
local and remote validation, receives protected-main review and merge, and is
the target of a separately verified annotated tag and matching GitHub Release.

This source extends existing `GRW-CAP-150-01` manuscript guidance. It does not
add a capability, create an installed runtime, authorize a real Study, read a
real manuscript, establish a result, approve a submission package, submit
material, or make a release decision.
