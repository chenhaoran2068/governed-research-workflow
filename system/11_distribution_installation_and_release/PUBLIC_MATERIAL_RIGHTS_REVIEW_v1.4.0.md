# Public Material Rights Review v1.4.0

Status: pre-C4 source-material review.

The v1.4 candidate contains only generic rules, blank templates, schemas,
validators, synthetic tests, and release records. It contains no real
descriptor catalogue, local descriptor value, source identifier, source body,
source locator, private path, inventory, source hash, human decision, mapping,
contributor material, credential, research data, manuscript, reviewer
material, or external requirement snapshot.

The candidate is a generic derivative prepared for public Apache-2.0 release
by the accountable maintainer. This review is not an identity, employment,
institutional-rights, contributor-rights, or C4 verification. Stop and seek a
new review if a real or third-party material is proposed for inclusion.
