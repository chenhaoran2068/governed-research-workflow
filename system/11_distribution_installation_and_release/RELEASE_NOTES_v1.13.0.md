# Governed Research Workflow v1.13.0

## Clarified

- The existing `GRW-CAP-180-01` future-Study lifecycle now explicitly orders
  candidate protocol/governance readiness, bounded decision-critical check,
  accountable-human outcome, and only then protocol lock and formal analysis.
- The four outcomes are `go`, `go_with_conditions`, `reframe`, and `stop`.
  Conditions must be resolved before their named later gate; neither continuing
  outcome makes a result authoritative by itself.

## Unchanged Boundaries

- No new capability identifier, schema, template, validator, dependency,
  Framework contract, Skill bridge, data access, network route, execution
  helper, runtime behavior, or automatic action.
- The System still does not create a Study, decide research design, infer
  governance, access real material, execute research, approve a result, submit
  material, or install itself.

## Compatibility

The frozen v1.0.0 public interface and exact Workspace Framework v0.4.0
contract remain unchanged. A public release and local installation require
their own exact annotated tag, matching GitHub Release, and local-adoption
evidence.
