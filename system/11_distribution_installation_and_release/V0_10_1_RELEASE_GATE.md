# v0.10.1 Release Gate

Status: active pre-C4 release gate for the self-controlled synthetic
experience-exchange pilot source. It is not a public-release, tag, runtime, or
installation statement.

## G101-1 Scope And Compatibility

- `GRW-CAP-101-01` is the only new capability in scope.
- v0.10 package schema `1.0.0` remains unchanged.
- The receipt validator is opt-in and reads only caller-named synthetic JSON.
- No public intake, external contributor, real content, network helper, or
  Computer B claim is admitted.

## G101-2 Material And Rights Boundary

- All added public files must be generic, blank, or synthetic.
- No local paths, credentials, real project material, personal data, clinical
  data, manuscript, attachment, or copyrighted source content may enter the
  public candidate.
- The separately private pilot repository is not public-package material and
  cannot prove external-contributor readiness.

## G101-3 Technical And Negative Evidence

- The complete local regression suite and focused v0.10/v0.10.1 tests pass for
  the exact candidate commit.
- The validator rejects path escape, link/reparse indirection, malformed or
  missing JSON, identity/revision/hash mismatch, and invalid correction or
  future-use relationships.
- It proves no directory discovery or file write for its named synthetic input.
- LF and CRLF JSON checkouts yield the same declared hash.

## G101-4 Pilot Evidence Boundary

- A private, maintainer-only, synthetic pilot may provide a remote-transport
  and clean-environment simulation.
- It must not be described as an external contributor, real user, physical
  Computer B, consent/right, transfer, deletion, recall, or promotion trial.
- Correction and future-use-stop simulations must use later commits without
  rewriting history.

## G101-5 Release Integrity

- Candidate source is built from immutable public `v0.10.0`.
- A fresh exact candidate commit must have public CI on Windows, Ubuntu, and
  macOS before protected-main review.
- Capability ledger, manifest, README, ROADMAP, SKILL, module map, tests, and
  release materials must agree.

## G101-6 Human Gates

- C3-remote may push only the reviewed exact candidate and open a reviewable
  pull request; it does not merge or release.
- C4 must name the protected-main commit, `v0.10.1` tag, release notes, and
  immutable GitHub Release operation.
- Public release does not authorize private canonical-source or runtime update.
