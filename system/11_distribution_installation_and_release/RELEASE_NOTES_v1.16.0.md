# v1.16.0 Release Notes

Status: versioned release-source notes. These notes do not prove a hosted
Release, installed runtime, external-source access, or C4 authorization.

## Added

- `GRW-CAP-240-01`: generic guidance for a declared manuscript-style-profile
  requirement stack, including journal-over-style-profile precedence and a
  visible manual-verification boundary;
- a blank JSON interchange template, Draft 2020-12 schema, explicit one-record
  read-only validator, and source-free synthetic fixtures; and
- route text that permits an existing Study's named local requirement stack to
  inform a manuscript-facing task after its exact Study root is supplied.

## Boundary

The addition contains no AMA Manual or other style-manual content. It does not
select or retrieve a profile, verify current reporting or journal requirements,
resolve a conflict, rewrite project facts, establish compliance, submit
material, or make a release decision.

Public installation for a selected version always requires an exact annotated
tag and matching GitHub Release under the normal verification rule.
