# v0.5.1 Release-State Maintenance Contract

Status: active maintenance-source contract. This record defines a documentation
and release-state correction only. It does not itself prove that v0.5.1 is a
published tag, an installation target, or an installed runtime.

## Scope

The correction applies to current-facing release identity, installation
guidance, support-line wording, capability-ledger context, relevant module
indexes, and regression tests. It preserves the v0.5.0 immutable tag and its
pre-C4 preparation records as historical evidence.

## Non-Goals

This revision does not alter the v0.5.0 Data And Provenance Register Set
validator, schemas, fixtures, direct dependency, data-content boundary,
permissions, workflow behavior, CI architecture, agent boundaries, or private

## Stable Rule

For every selected version, a normal public installation target exists only
when an exact annotated tag and matching GitHub Release resolve to the selected
source commit. A mutable branch, passing CI, capability ledger, AI statement,
or local checkout cannot substitute for this verification. A public release
does not prove a private canonical source or installed runtime has changed.

## Historical Boundary

Pre-C4 gate, evidence, rights-review, admission, release-note, and synthetic
assurance files retain their historical wording and purpose. They must be
explicitly labeled as historical and cannot override the stable rule or a
verified published tag/Release identity.
