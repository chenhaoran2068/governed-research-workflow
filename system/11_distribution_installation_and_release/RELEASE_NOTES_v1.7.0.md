## Boundaries

The new public material is generic guidance only. It does not disclose private
experience records, source identities, paths, decisions, mappings, receipts,
projects, Studies, or unpublished material. It does not provide authority,
current external requirements, source access, automated loading,
synchronization, task execution, delegation, agent runtime, or release
authority.
