# Governed Research Workflow v1.11.0

## Added

- `GRW-CAP-210-01`, a narrow public boundary for an explicitly requested
  reading of one specified scholarly paper.
- Optional, non-automatic referral guidance to a separately maintained
  `research-paper-reading` Skill.

## Boundaries

- Paper-reading requests do not become a possible new Study unless the user
  also clearly asks to start, plan, explore, or create a Study.
- No Skill discovery, invocation, installation, source reading, PDF download
  or copying, retention, manager or Framework inspection, dossier, knowledge,
  experience, mapping, promotion, rule, or Study creation.
- No Framework behavior, data access, governance finding, external service
  action, public source verification, or runtime claim.

## Compatibility

The frozen v1.0.0 public interface and the exact Workspace Framework v0.2.0
contract remain unchanged. A public release and local installation require
their own exact tag, matching Release, and local-adoption evidence.
