# v1.15.0 Release Gate

Release remains blocked until the selected candidate commit passes declared
local and remote validation, receives protected-main review and merge, and is
the target of a separately verified annotated tag and matching GitHub Release.

This source adds `GRW-CAP-230-01`. It does not select a review profile, create
or read a real Study, evaluate a review or result, approve a package, execute a
rerun, submit material, create an installed runtime, or make a release decision.
