# v1.9.2

This maintenance release retains `GRW-CAP-190-01`. It strengthens the Research
System entry metadata for ordinary-language possible-new-Study requests and
requires the first substantive navigator response to begin
`Route: <recommendation-code>`, using one existing human-confirmable route.

It preserves the stop before methods, lifecycle guidance, external sources,
citations, links, data-access suggestions, or project creation. It does not
guarantee host-level automatic System selection and adds no capability
identifier, schema, validator, dependency, Framework change, data action,
research executor, external service action, agent runtime, or automatic
installation.

The public package does not configure a user's global Codex `AGENTS.md`.
Any local startup-registration configuration is separately reviewed and
activated after a selected public version is installed.
