# v1.8.0 Public Material Rights Review

The v1.8.0 public candidate contains generic guidance, blank templates,
schemas, a read-only validator, and synthetic fixtures only. It excludes
private paths, local evidence, source identifiers, real Study records, real
data, ethics/access material, unpublished manuscripts, and runtime receipts.

This review is a bounded source-material assessment. It is not a release,
license, institutional, privacy, or consent determination for any later
material.
