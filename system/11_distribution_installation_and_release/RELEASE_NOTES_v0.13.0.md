# v0.13.0 Release Notes

Status: versioned release-source notes. This file describes bounded source
scope only and does not by itself prove an annotated tag, matching GitHub
Release, installation target, or runtime update.

## Added

- `GRW-CAP-130-01`, a versioned V1 Support Scope Matrix that classifies all
  thirteen public modules as explicitly bounded support surfaces with named
  external boundaries, v1 exclusions, compatibility/migration posture,
  maintenance ownership, evidence, limitations, and refusal semantics.
- A JSON Schema, human-readable support guide, capability-ledger admission,
  and regression tests that prevent missing modules, unsupported posture,
  accidental scope expansion, authority conflation, or historical-current
  identity drift.
- Versioned release-preparation records for the matrix scope, public-material
  boundary, dependency/workflow review, release gate, and evidence.

## Boundaries

- v0.13 adds no research-operation interface, data-content action, data-access
  decision, manuscript handling, external source retrieval, network action,
  credential use, intake, upload/download, agent runtime, coordinator,
  delegation, multi-agent orchestration, generic writer, installer, migration
  executor, recovery executor, automatic push, tag, Release, or runtime
  replacement.
- Matrix posture is structural support-contract information. It does not prove
  task fitness, factual truth, source currentness, authorization, rights,
  compliance, Gate passage, release status, or installation status.
- `active_bounded` does not mean that every directory, historical document,
  or function named by a module is available or supported in v1.

## Compatibility

Existing bootstrap behavior, read-only validators, capability records, schemas,
dependencies, supported profiles, framework identity, and CI architecture are
unchanged. Existing public users do not need a data, record, or runtime
migration to read the matrix. Public Release, private canonical source
adoption, and Codex runtime installation remain separate controlled decisions.
