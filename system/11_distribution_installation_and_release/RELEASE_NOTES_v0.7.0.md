# Release Notes: v0.7.0

Status: candidate Release-notes source. This file describes the proposed v0.7
scope and does not itself establish publication, installation eligibility, C4
authorization, or runtime identity. Verify a selected version through its
exact annotated tag and matching GitHub Release.

## Proposed Addition

- metadata-only Human-Reviewed Lesson Promotion Control Records with five
  typed records: observations, lesson candidates, represented human decisions,
  integration verification, and visible correction/withdrawal/supersession
  events;
- a blank template, synthetic valid example, and an explicitly invoked
  read-only structural validator; and
- refusal checks that prevent automatic-promotion declarations, unsafe input
  paths, silent decision/integration mismatches, and hidden supersession.

## Explicit Non-Additions

v0.7.0 does not read project material or data, follow pointers or URLs, verify
a person's identity or actual authority, automatically promote or integrate a
lesson, change a target rule or workflow, provide an agent runtime, make a
scientific/compliance/Gate/submission/release decision, or synchronize/install
a local runtime.
