# V1.4.0 Release Gate

Status: pre-C4 gate. All items require exact, separately controlled evidence
before a C4 decision.

- [ ] Exact candidate commit is created from the reviewed public candidate.
- [ ] Full local test suite and source-free boundary review pass.
- [ ] Windows, Ubuntu, and macOS CI all pass for the exact candidate commit.
- [ ] Public-material rights, privacy, secret, and license review pass.
- [ ] Protected-main merge commit is reviewed separately.
- [ ] Accountable human approves the exact commit, annotated v1.4.0 tag, and
      matching GitHub Release notes.
- [ ] Post-release review verifies tag, Release, source archives, and current
      public status.

No checked item is a runtime-adoption claim. Public release and local
controlled adoption remain separate.
