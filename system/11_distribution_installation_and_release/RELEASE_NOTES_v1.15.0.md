Status: versioned release-source notes. These notes do not prove a hosted
Release, installed runtime, or C4 authorization.

## Boundary

The addition does not select a profile, discover or read a Study, follow a
reference, assess scientific adequacy, accept/reopen a package, rerun work,
verify a human decision, submit material, or make a release decision.

Public installation for a selected version always requires an exact annotated
tag and matching GitHub Release under the normal verification rule.
