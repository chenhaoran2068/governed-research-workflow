# v1.19.0 Release Gate

Release remains blocked until the exact candidate passes local System tests,
local Framework v0.5.0 integration checks, public-boundary review,
protected-main review, and the repository CI matrix. It then requires a
separately verified annotated tag and matching GitHub Release.

This candidate clarifies the existing human-reviewed Research Program boundary
for an optional Framework v0.5.0 index. It must not include a real Program or
Study, local path, data, credential, result, manuscript, private decision, or
adoption receipt. It does not scan a workspace, create a Program, move a Study
root, transfer authority, or grant access.
