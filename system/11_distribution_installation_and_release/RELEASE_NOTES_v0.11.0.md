# v0.11.0 Release Notes

Status: versioned release-source notes. This file describes bounded source
scope only and does not by itself prove an annotated tag, matching GitHub
Release, installation target, or runtime update.

## Added

- Five optional blank generic templates for manuscript assembly and
  claim/display review, reviewer-response and revision trace, declaration and
  AI-use fact boundaries, submission route/package provenance, and a
  decision-ready human-review packet.
- Exactly 38 generic public knowledge-governance experiences: 14 adapted
  public experience rules and 24 redacted historical experience notes.
- A backward-compatible extension of the existing capability-ledger identifier
  pattern so it can represent `GRW-CAP-110-01` through `GRW-CAP-110-06`.

## Boundaries

- The public materials are blank, generic, or synthetic. They do not contain
  real manuscripts, reviewer/editorial correspondence, declarations,
  submission packages, project records, source payloads, private identifiers,
  credentials, or restricted data.
- The experience collection is not a `Knowledge` package, source library,
  registry, index, retrieval service, RAG capability, access grant, or
  current-source checker.
- No new schema artifact, validator, dependency, helper, intake, upload or
  download route, data access, external action, generic writer, recovery
  executor, agent runtime, delegation, or multi-agent orchestration is added.
- A template, experience entry, or ledger state does not establish a fact,
  rights, consent, policy compliance, authorship, scientific support,
  submission authority, hosted Release, or local runtime identity.

## Compatibility

Existing v0.4-v0.10.2 records, helpers, validators, profile boundaries, direct
dependency, and framework compatibility declaration remain unchanged. The
existing capability ledger remains readable with its backward-compatible
identifier-pattern extension. Public Release, private local source adoption,
and Codex runtime installation remain separate controlled decisions.
