# Governed Research Workflow v1.14.0

## Added Guidance

- The existing `GRW-CAP-150-01` manuscript guidance now describes a
  Results-first drafting and review sequence: finish and review Results before
  working through Methods, Discussion/Conclusion, Introduction,
  Abstract/Summary, and submission-facing material.
- Results guidance now includes display-first, parallel, and provisional-prose
  assembly modes; a nested review sequence; and documented exceptions for an
  article type or journal format that requires another order.

## Unchanged Boundaries

- No new capability identifier, schema, template, validator, dependency,
  Framework contract, Skill bridge, data access, network route, execution
  helper, runtime behavior, or automatic action.
- The System still does not create a Study, write a real manuscript, decide a
  research design, infer governance, access real material, approve a result,
  submit material, or install itself.

## Compatibility

The frozen v1.0.0 public interface and exact Workspace Framework v0.4.0
contract remain unchanged. A public release and local installation require
their own exact annotated tag, matching GitHub Release, and local-adoption
evidence.
