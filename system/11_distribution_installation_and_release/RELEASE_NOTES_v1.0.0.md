# V1.0.0 Release Notes

Status: versioned v1 release-source notes. They describe the frozen contract
only and do not themselves prove a tag, GitHub Release, installation target,
or runtime update.

## Frozen Contract

- A V1 Public Interface Manifest enumerating the thirteen bounded public
  module interfaces, their paths, effect class, linked capability IDs, promises,
  and non-promises.
- A V1 Capability Verification Map covering every ledger capability and naming
  interface, negative-boundary, and full-regression requirements.
- An evolved V1 Support Scope Matrix whose `interface_frozen` status is
  contract maturity, not a hosted-release claim.
- Clear separation between historical capability evidence, local candidate
  verification, exact public Release identity, and installed runtime identity.

## No New Operational Capability

v1.0.0 adds no data-content operation, network action, intake, upload/download
helper, source retrieval, RAG, agent runtime, delegation, multi-agent
orchestration, generic writer, installer, automatic release, or local runtime
replacement. The existing empty-workspace bootstrap remains the only
side-effecting public helper and retains its own preview/confirmation boundary.

## Compatibility

The public profiles remain `standalone` and `framework_integrated`.
Existing schemas, validators, templates, dependencies, framework contract, and
CI architecture retain their bounded behavior. A structural contract pass does
not prove truth, access, compliance, human approval, publication readiness, a
hosted release, or a runtime installation.
