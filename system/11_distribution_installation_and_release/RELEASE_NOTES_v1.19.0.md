# Governed Research Workflow v1.19.0

v1.19.0 is a zero-new-capability compatibility and boundary clarification
candidate derived from v1.18.1.

It:

- aligns the existing Research Program boundary guidance with the optional
  Framework v0.5.0 instance-local Program index;
- distinguishes an upper-level Research Program from Study-level legacy
  `project_id` and `project_manifest` vocabulary;
- requires caller-named Program and Study locations rather than workspace
  discovery; and
- requires explicit boundaries around membership, shared references, authority,
  and access.

It does not create or discover a Program, read a private Study, move Study
roots, copy material, decide membership, grant data access, or advance a
Study's lifecycle.
