# v0.6.0 Public Material And Rights Review

Status: v0.6 release-source review checklist. This checklist is not a rights
opinion, security certification, C4 authorization, or public Release evidence.

Before C4, review the exact source commit and newly reachable history for:

- real project, patient-derived, restricted, credentialed, or unpublished
  material;
- private local paths, account identifiers, secrets, tokens, keys, or URLs
  carrying credentials/query material;
- copied third-party source content, unreviewed licenses, or generated assets;
- synthetic fixture status, empty-template status, and absence of real source
  pointers or payloads;
- Apache-2.0 publication authority for the exact generic tree; and
- planned Release assets, archives, dependency changes, workflow changes, and
  Git LFS/submodule state.

Any uncertain item stops the affected release claim and requires an
accountable-human decision with documented alternatives and risks.
