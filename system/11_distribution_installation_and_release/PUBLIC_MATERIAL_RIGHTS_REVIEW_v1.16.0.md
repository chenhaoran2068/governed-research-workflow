# Public Material Rights Review v1.16.0

## Reviewed Public Material

The proposed v1.16.0 addition contains generic style-profile guidance, a blank
metadata template, structural schema, read-only validator, source-free
synthetic fixtures/tests, and release-control documents authored for this
package.

## Exclusions

The public candidate must not contain an AMA Manual, other copyrighted style
manual, journal instruction snapshot, private path, Study name, protocol,
data, code output, ethics/access/registration evidence, result, manuscript,
figure, table, review correspondence, source material, user decision, runtime
receipt, credential, or copied external scholarly content.

## Review Result

The material is suitable for Apache-2.0 publication only as generic source
code and documentation, subject to the accountable human's separate release
decision. This review does not establish rights for a real Study, external
style source, hosted Release, or installation target.
