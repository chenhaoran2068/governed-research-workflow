# v1.9.1

This maintenance release retains `GRW-CAP-190-01` and hardens the possible-new-
Study first-response boundary. Before methods, lifecycle guidance, external
sources, citations, links, data-access suggestions, or project creation, the
skill returns one human-confirmable route recommendation with visible facts,
unknowns, risks, and the user's choices to accept, revise, defer, or reject.

For causal or treatment-effect wording, it names the separate causal-design or
target-trial-emulation review and stops. For prospective, researcher-assigned,
or randomized wording, it names the specialist trial route and stops.

It adds no capability identifier, schema, validator, dependency, Framework
change, data action, research executor, external service action, agent runtime,
or automatic installation.
