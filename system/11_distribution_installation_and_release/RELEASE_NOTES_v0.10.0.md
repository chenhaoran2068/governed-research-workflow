# v0.10.0 Release Notes

Status: versioned release-source notes. This file describes scope only and does
not by itself prove a tag, matching GitHub Release, installation target, or
runtime update.

## Added

- One voluntary metadata-only experience-package contract with five blank
  records for observation, contribution scope, redaction/rights representation,
  maintainer review, and correction/withdrawal metadata.
- One explicit read-only structural validator, generic trial package, and
  synthetic boundary/no-write/same-host receipt tests.

## Boundaries

- No intake, real-contribution transfer, telemetry, account, real-content handling,
  Computer B test, cross-device claim, automatic review/promotion, or remote
  correction/withdrawal execution.
- A schema pass does not prove truth, consent, authority, rights, privacy,
  content safety, acceptance, or recall.

## Compatibility

Existing v0.4-v0.9 schemas and records remain unchanged. Public Release and
private runtime adoption remain separate later decisions.
