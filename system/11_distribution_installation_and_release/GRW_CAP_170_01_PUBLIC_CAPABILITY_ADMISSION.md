# GRW-CAP-170-01 Public Capability Admission

## Candidate Scope

`GRW-CAP-170-01`, Public Collaboration Guidance Derivatives, adds two generic
System-owned guidance documents, three generic public experience cards, and
three public navigation topics. It retains the historical 38-card KGE-derived
library without rewriting the KGE identifiers.

## Promise

The package provides selective public guidance about substantive
reader-facing delivery, visible plan state, controlled plan changes, and
governed task initiation. It may be installed as files with an explicitly
selected System version and selectively read for a relevant task.

## Non-Promise

It contains no private source, identifier, local path, hash, receipt,
decision, mapping, project, Study, or unpublished material. It is not a
source library, RAG corpus, current-requirement checker, approval mechanism,
promotion mechanism, automatic recommendation or loading service, task
executor, delegation service, agent runtime, or release decision.

## Verification Boundary

The capability requires structural validation of the public vocabulary,
catalogue, cards, schemas, and negative fixtures, plus explicit checks of both
new guidance documents and the public boundary. A local candidate does not
prove remote CI, protected-main review, C4 publication, private-source
activation, or installed-runtime identity.
