# Workflows Module Boundary

Status: foundation only; no standalone public workflow module is admitted here
yet.

This module will hold reusable, bounded procedures for startup, feasibility,
manuscript work, citation control, submission routing, and retrospective
learning. A workflow must identify its required inputs, allowed outputs,
human-controlled decisions, stop conditions, and records.

Do not put a real study timeline, manuscript, result, protocol, or submission
package in this module. Current `v0.2.1` route guidance remains authoritative
in `references/`.
