# Governance Module Boundary

The v0.13 V1 Support Scope Matrix is the machine-readable authority for this
module's support posture; this boundary record does not enlarge that scope.

Status: active baseline.

The active governance baseline remains deliberately thin: `SKILL.md` defines
human accountability, authority boundaries, and consequential-action stops;
the focused route references provide the supporting procedures. This module
maps those active controls without duplicating them.

Before admission, each rule must state its scope, trigger, required evidence,
stop condition, record, and validation method. Do not place clinical decisions,
ethics facts, DUA terms, or project-specific approval records here.

Future generic governance records may be admitted here only after the stated
review. Current route guidance remains authoritative in `SKILL.md` and
`references/`.

The v0.4.0 release source adds a bounded-autonomy authorization record for an
explicit, time-limited human-reviewed task boundary. It does not create an
executor, tool permission, data authority, or automatic state transition.
