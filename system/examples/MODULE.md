# Examples Module Boundary

Status: foundation only; no example is admitted here yet.

This module will hold synthetic or independently releasable examples used to
demonstrate installation, routing, templates, or tests. Every example needs a
material-boundary review and an explicit statement that it does not establish
scientific, clinical, regulatory, or journal compliance for a real project.

Do not include real study data, manuscript text, reviewer correspondence,
submission records, project memory, or identifiable case details.
