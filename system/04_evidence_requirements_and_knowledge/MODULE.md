# Knowledge Module Boundary

Status: active guidance; no curated knowledge corpus.

The active baseline is the external-evidence and citation-control route
guidance in `references/`. It requires source-specific support for project
claims but bundles no source corpus. This module may later hold reviewed
generic guidance, source pointers, provenance notes, evidence-refresh rules,
and independently reusable knowledge summaries. It must distinguish a source
pointer from evidence that supports a particular project claim.

Do not bundle restricted datasets, credentials, private notes, copyrighted
full-text material without redistribution rights, or journal requirements as
permanently current facts.
