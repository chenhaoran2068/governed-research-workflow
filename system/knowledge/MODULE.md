# Knowledge Module Boundary

Status: foundation only; no curated knowledge collection is admitted here yet.

This module will hold reviewed generic guidance, source pointers, provenance
notes, evidence-refresh rules, and independently reusable knowledge summaries.
It must distinguish a source pointer from evidence that supports a particular
project claim.

Do not bundle restricted datasets, credentials, private notes, copyrighted
full-text material without redistribution rights, or journal requirements as
permanently current facts.
