# Memory And Learning

Status: active retrospective-learning baseline with a v0.7 release-source
lesson-promotion control record contract.

Use `references/retrospective-learning.md` and the blank retrospective register
only after a bounded project observation is available. Project observations are
not global rules. Promotion requires explicit human review and a verified
integration target such as a rule, workflow, template, checklist, or skill.

For a selected public release whose capability ledger admits
`GRW-CAP-070-01`, the metadata-only lesson-promotion control bundle can record
an observation, a local lesson candidate, an accountable-human decision, a
verified integration reference, and a correction, withdrawal, or supersession
event. Its read-only validator checks declared structure only. It never reads
project content, proves a human identity or authority, automatically promotes
a lesson, changes a shared rule, or publishes project history.

This module does not provide a shared private-memory store or publish project
history.
