# Public Knowledge-Governance Experience Collection

## Purpose And Boundary

This is a collection of generic public experiences about governing source and
knowledge work. It is not a `Knowledge` content package, source library,
registry, index, retrieval service, RAG system, current-source checker, or
production-readiness certificate. It contains no source payload, extracted
text, transformed note, curated card, retrieval output, local path, project
record, private project, source, or person identifier, hash, receipt, trace,
or approval history. The public `KGE-001` through `KGE-038` identifiers name
only the entries in this collection.

Each entry is either an `adapted_public_experience_rule` or a
`redacted_historical_experience_note`. The rule type is reusable guidance only
within its stated scope. The historical-note type records a generalized lesson
without becoming current binding authority. Neither type authorizes access,
copying, transformation, sharing, publication, retrieval, or external action.

## Use Rule

Use an entry only as a prompt for proportionate human review in a new task.
Compare the new task's owner, material class, authority, environment, and risk
before reuse. Do not treat a similar title, an earlier pilot, or a completed
entry as authority to access sources, process content, contact a service, or
publish material.
