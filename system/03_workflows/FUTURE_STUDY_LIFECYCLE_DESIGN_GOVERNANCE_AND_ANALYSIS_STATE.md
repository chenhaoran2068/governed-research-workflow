# Future-Study Lifecycle, Design, Governance, And Analysis State

This module surface routes the generic eleven-stage future-Study lifecycle and
the four independent declared-metadata records. It is read only for an
explicitly requested lifecycle, design-classification, governance-readiness, or
analysis-state/freeze task. The authoritative route guide is
`references/future-study-lifecycle-design-governance-and-analysis-state.md`.

Stage 5 forms a candidate, not-yet-locked protocol and governance readiness.
Stage 6 begins with a bounded decision-critical check and an accountable-human
`go`, `go_with_conditions`, `reframe`, or `stop` decision. Only a continuing
decision permits protocol lock and formal analysis.

It does not create a Study, infer design or governance facts, execute analysis,
or duplicate submission-route authority. Project-specific editorial/revision
control remains separately governed by the applicable submission lifecycle.
