# New-Study Navigator And Route Recommendation

This module surface provides generic, human-governed new-Study navigation for
natural-language possible-new-Study intent. Its authoritative public guide is
`references/new-study-navigator-and-route-recommendation.md`.

It is the first substantive route for a possible new Study. It may identify
visible facts, material unknowns, and one human-confirmable route
recommendation before methods, lifecycle guidance, external sources, citations,
links, data-access suggestions, or project creation. It does not create a
Study, decide research type or design, infer governance, access data, execute a
feasibility probe, or replace an accountable-human decision.
