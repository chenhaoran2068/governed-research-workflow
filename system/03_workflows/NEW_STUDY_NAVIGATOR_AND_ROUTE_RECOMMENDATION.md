# New-Study Navigator And Route Recommendation

This module surface provides generic, human-governed new-Study navigation for
natural-language possible-new-Study intent. Its authoritative public guide is
`references/new-study-navigator-and-route-recommendation.md`.

It may identify visible facts, material unknowns, and one human-confirmable
route recommendation. It does not create a Study, decide research type or
design, infer governance, access data, execute a feasibility probe, or replace
an accountable-human decision.
