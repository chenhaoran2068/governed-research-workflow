# Governance Module Boundary

Status: foundation only; no standalone public governance module is admitted
here yet.

This module will hold generic controls for human accountability, source and
authority boundaries, consequential-action stops, public/private separation,
and release governance.

Before admission, each rule must state its scope, trigger, required evidence,
stop condition, record, and validation method. Do not place clinical decisions,
ethics facts, DUA terms, or project-specific approval records here.

Current `v0.2.1` route guidance remains authoritative in `references/`.
