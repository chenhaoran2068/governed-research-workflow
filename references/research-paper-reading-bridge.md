# Research-Paper Reading Bridge

## Purpose

`GRW-CAP-210-01` provides a narrow, metadata-only boundary between a possible
new-Study request and an explicit request to read, understand, annotate,
discuss, or critically appraise one specified scholarly paper. The latter is a
paper-reading request unless the same request clearly asks to start, plan,
explore, or create a Study.

The bridge may identify `research-paper-reading` as an optional separately
maintained Skill. It does not discover, invoke, install, configure, or verify
that Skill. A separately admitted managed-reading knowledge-service handoff,
when configured by the reading Skill and explicitly requested for a named
existing Study, is governed only by
`managed-reading-knowledge-service-bridge.md`.

## Explicit Handoff Boundary

Use this bridge only after the user explicitly requests a paper-reading task.
The user must separately choose the reading route and authorize any source
scope or retention. The reading Skill, not this System bridge, determines its
own permitted source, reading objective, retention mode, reference-manager
boundary, and optional Framework knowledge-service prerequisites.

Do not read, download, copy, parse, quote, summarize, index, classify, or
retain a paper through this bridge. Do not inspect a reference manager,
workspace, or Framework configuration. Do not create a reading dossier,
knowledge card, vocabulary record, experience record, mapping, rule,
promotion proposal, or Study handoff.

## Scope Stops

This bridge is not a source-verification service, literature review,
systematic-review route, research-design route, Study bootstrap, knowledge
service, RAG system, reference-manager synchronizer, or authority mechanism.
It does not establish that a paper exists, is current, is accessible, is safe
to retain, supports a claim, or may be used in a Study. It does not establish
an installed Skill, Framework configuration, manager configuration, human
decision, public Release, or runtime.
