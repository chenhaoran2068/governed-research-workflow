# Research-Ethics Preparation Bridge

## Purpose

`GRW-CAP-200-01` provides a generic, explicit route from a confirmed
future-Study lifecycle to a user-named compatible ethics-preparation module. It
does not invoke a module automatically, discover a Study, create material,
access an external service, establish an ethics/access/registration fact, or
advance a governance gate.

## Eligibility Navigation

After Stage 5, state only one of these non-decisional outcomes:

| Outcome | Meaning |
| --- | --- |
| `eligible_for_research_ethics_v1_preparation` | The visible request may fit the compatible module's declared V1 scope; the human still must request preparation and verify current conditions. |
| `eligible_with_institutional_or_specialist_conditions` | A route may be possible, but required facts or separate specialist/institutional review remain unresolved. |
| `outside_research_ethics_v1_scope` | The request is not within the compatible module's declared route. |

No outcome is approval, registration, access permission, institutional
compliance, feasibility, or an instruction to process real material.

## Explicit Invocation Boundary

Proceed only when the human names all of the following in the current request:

1. one compatible module and its caller-supplied public manifest;
2. one exact Study root;
3. `actual_submission` or `test_public` material mode;
4. the exact protocol and compliance inputs permitted for this task; and
5. the requested preparation deliverable.

Do not scan for modules or projects, resolve a reference, read a source target,
call an installed Skill automatically, or retain an undisclosed module as
memory. A missing condition requires a focused question or stop, not discovery.

## Authority And Outputs

The current protocol remains authoritative in `03_protocol/`. A compatible
module may produce only clearly derived preparation drafts in
`03_protocol/derived/ethics_preparation/<package_id>/` when the human authorizes
that exact destination. Actual application, submission, approval, waiver,
consent, amendment, access, and registration evidence belongs in
`02_registry/compliance/`, especially
`01_ethics_and_consent/`. Human decisions remain separately referenced from
`00_state/lifecycle/`.

Do not let a module manifest, draft, template, field check, or generated Word
file replace the protocol, prove a governance fact, or authorize a formal run.

## Scope Stops

The initial compatible ethics module is limited to China Mainland,
researcher-initiated observational preparation. It does not cover prospective
researcher-assigned, randomized, interventional, product, device, IVD, or
non-China routes. Treatment-effect language first requires the separate
causal-design or target-trial-emulation review; this bridge cannot decide that
review.

## Currentness And Maintenance

Before an actual submission task, the accountable human must verify current
official platform, institution, ethics committee, jurisdiction, and
project-specific requirements. An installed module is not a currentness claim.
The compatible module must publish a maintenance trigger policy and review
public sources at least every 90 days. A bridge semantic or authority/path
change requires coordinated System and module review; a new jurisdiction or
research type requires a separate Charter.
