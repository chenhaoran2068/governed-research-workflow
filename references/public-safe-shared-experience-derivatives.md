# Public-Safe Shared-Experience Derivative Guidance

For a selected released System version that admits `GRW-CAP-160-01` and, when
present, `GRW-CAP-170-01`, the public library at
`assets/public-experience-derivatives/` provides a vocabulary, a catalogue,
and generic public guidance cards. The catalogue is the only current public
discovery index. Historical KGE-derived cards carry a backward reference; new
public-safe derivatives have no KGE predecessor.

Use this route only for an explicitly requested task where public generic guidance may be relevant. Read the catalogue first and then only the selected card or cards. Do not load the complete library merely because this System is installed, and do not use a card as a substitute for current requirements, source review, accountable-human approval, or a formal System rule.

The library contains no private source text, private identifier, local path,
hash, receipt, decision record, mapping, project fact, or Study-local material.
It must not be used to infer private provenance, administer a vocabulary,
create a mapping, promote an experience, alter a rule, obtain material, or
perform a network action.

For public structural validation only, invoke `scripts/validate_public_experience_derivatives.py` with caller-named public vocabulary, catalogue, and card-root paths. The validator is read-only. It does not discover a workspace, resolve a source pointer, read private material, contact a network target, mutate input, or write output.
