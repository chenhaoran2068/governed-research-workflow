# Family-Level Metadata Before Content Work

## Applicable Context

Registering a source family with metadata first.

## Generic Experience

Keep family-level description separate from content acquisition and interpretation.

## Recommended Behavior

Register only bounded family description and retain a separate review boundary for later work.

## Exclusions And Stop Conditions

Registration does not grant access or verify completeness. Stop when a family description exposes restricted details.
