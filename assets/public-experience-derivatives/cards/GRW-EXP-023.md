# Reassess Each Additional Object

## Applicable Context

Admitting a second controlled object.

## Generic Experience

Reassess identity, rights, and transformation conditions for each new object.

## Recommended Behavior

Compare the object conditions directly instead of assuming earlier eligibility transfers.

## Exclusions And Stop Conditions

Similarity to an earlier object is not proof of reuse eligibility. Stop when the second object changes governing conditions.
