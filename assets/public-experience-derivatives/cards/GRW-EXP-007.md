# Narrow Single-Object Dry Run

## Applicable Context

Conducting a single-object dry run.

## Generic Experience

Keep the first exercise narrow enough to inspect assumptions and refusal behavior.

## Recommended Behavior

Limit the material class and record the conditions that would require a new scope.

## Exclusions And Stop Conditions

A dry run is not proof of scalable production readiness. Stop when expansion would add a new material class or authority.
