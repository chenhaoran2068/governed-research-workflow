# Recheck Inputs and Outputs for Reuse

## Applicable Context

Reproducing an extraction step for a second object.

## Generic Experience

Re-check declared inputs and outputs instead of assuming an earlier route transfers.

## Recommended Behavior

Compare the new object transformation and authority requirements before rerunning a procedure.

## Exclusions And Stop Conditions

A repeated procedure does not prove equivalent results. Stop when the new object requires a different transformation or authority.
