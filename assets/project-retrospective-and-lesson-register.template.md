## Close-The-Loop Check

- [ ] Each observation has minimal evidence pointers or is labeled as a working explanation.
- [ ] No restricted data, credentials, private prompts, unpublished content, or confidential correspondence is copied here.
- [ ] Local observations are not presented as universal rules.
- [ ] Existing guidance is linked rather than duplicated.
- [ ] A reusable candidate has an explicit human decision.
- [ ] An accepted promotion identifies and validates the live artifact changed.
