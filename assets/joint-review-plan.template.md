# Joint Review Plan Template

Use this blank aid only after a human has selected the applicable review
profile. The matching JSON record is the structural record; this Markdown
template is explanatory only.

## Package Plan

For the observational empirical original-research route, list the applicable
R0 through R10 packages in order. Record each package's purpose, planned
action, authority references, review state, and any accountable-human decision
reference. Do not turn a blank plan or structural validation into a Study,
approval, result, or publication claim.

## Results Work Units

For R4 only, record the work-unit identifier, assembly mode
(`display_first`, `parallel`, or `text_provisional`), current state, display
reconciliation state, and supplied references. A provisional text unit remains
provisional until its planned display is reconciled.

## Reopen Events

Record a later change only when it affects the accepted review surface. State
the trigger class, affected packages, downstream effect, QA or rerun status,
replacement reference if any, and accountable-human decision reference.

## Boundary

This aid does not read a Study, follow a reference, check a manuscript or
result, decide a profile, verify reporting guidance, authorize work, or make a
scientific, governance, submission, or release decision.
