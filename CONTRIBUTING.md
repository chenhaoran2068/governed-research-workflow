# Contributing

Contributions should improve the public routing skill, blank templates, and
public documentation without turning this repository into a storage location
for research projects.

## Before Proposing a Change

- Keep the change within the declared public scope.
- Use generic, independently written material.
- Do not submit patient data, restricted data, credentials, private paths,
  unpublished manuscripts, reviewer correspondence, source PDFs, author or
  institution details, or copied private workflow records.
- Do not add executable helpers, dependencies, or compatibility claims without
  a separately reviewed proposal and tests.
- Do not claim that a workflow instruction proves scientific, clinical,
  ethical, legal, or journal correctness.

## Change Expectations

Explain the user problem, the files changed, the boundary impact, and how the
change was checked. Update ROADMAP.md when a capability is added, deferred,
promoted, revised, or retired.

Report suspected security issues through the route stated in SECURITY.md, not a
public issue or pull request.

## Maintainer Review

Maintainers review scope, privacy, rights, provenance, safety wording, and
regression impact before accepting a change. A public contribution never
automatically changes a private research system or any installed local skill.
